FEED FLOW 관리자 통계·활동 이력 안내

1. 관리자 로그인
- 메인 화면의 로그인 창에서 관리자 계정으로 로그인합니다.
- 관리자 계정은 Spring Boot 실행 환경변수의
  FEEDFLOW_ADMIN_USERNAME, FEEDFLOW_ADMIN_PASSWORD 값을 사용합니다.
- 로그인에 성공하면 /admin 관리자 화면으로 이동합니다.

2. 통계 대시보드
- 누적 결제 매출과 오늘 결제 매출
- 전체 주문과 오늘 주문
- 결제완료 주문과 배송중 주문
- 전체 상품과 품절 상품
- 재고 10개 이하 LOT
- 유통기한이 30일 이내이거나 이미 지난 LOT
- 최근 7일의 결제완료 주문 건수와 매출 그래프

통계 매출은 결제상태가 DONE인 주문만 포함합니다.
취소되었거나 결제가 완료되지 않은 주문은 매출에서 제외됩니다.

3. 관리자 활동 이력
다음 작업을 수행하면 관리자 아이디, 대상, 설명, 접속 IP와
처리 시각이 admin_activity_log 테이블에 자동 저장됩니다.

- PRODUCT_CREATED: 상품 등록
- PRODUCT_UPDATED: 상품 수정
- PRODUCT_DEACTIVATED: 상품 비활성화
- ORDER_STATUS_CHANGED: 주문 상태 변경

관리자 화면의 '활동 이력' 메뉴에서 최근 100건을 확인할 수 있습니다.
활동 이력은 감사 자료이므로 일반 화면에서 수정하거나 삭제할 수 없습니다.

4. 발표 시연 순서
1) 관리자 로그인
2) 통계 대시보드의 매출·주문·재고 경고 설명
3) 주문 관리에서 결제완료 주문을 상품준비중으로 변경
4) 활동 이력에서 ORDER_STATUS_CHANGED 기록 확인
5) 상품을 하나 등록하고 PRODUCT_CREATED 기록 확인
