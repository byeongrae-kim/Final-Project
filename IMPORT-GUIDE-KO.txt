FEED FLOW 최종 수정본 Import 안내
=================================

[반영된 수정]
1. 로그인/비밀번호 찾기 버튼 동작 복구
   - 일반 회원 로그인 성공 후 메인페이지로 이동
   - 관리자 로그인 성공 후 판매자센터로 이동
2. 비밀번호 재설정 시 회원가입과 동일한 유효성 검사
   - 8~64자
   - 영문, 숫자, 특수문자 포함
   - 비밀번호 확인 일치 검사
3. 휴대전화 010-1234-5678 자동 표시
4. DB에 하이픈이 있거나 없어도 같은 전화번호로 확인
5. 메인·로그인 창·마이페이지·푸터·관리자 화면의 모든 로고를
   오른쪽 FARM ACCOUNT 카드처럼 심볼과 FEED FLOW 글자가 모두 보이도록 통일
6. Kakao 우편번호 주소 검색
   - 회원가입 자택 주소와 농장 주소
   - 주문·결제 배송지 주소
7. 결제 API 연동 구조
   - PortOne V1 통합 결제(impXXXXXXXX 고객사 식별코드 방식)
   - 신용카드: PortOne 카드 PG 채널
   - 카카오페이: PortOne 카카오페이 채널
   - 무통장입금: PortOne 가상계좌 PG 채널
   - 서버 결제 조회 검증 및 V1 웹훅 처리
   - 상세 키 설정은 PAYMENT-API-GUIDE-KO.txt 참고
8. 기존 H2 결제 컬럼 자동 마이그레이션
   - KAKAO/TOSS만 허용하던 기존 payment_provider 컬럼을 PORTONE 호환 형식으로 자동 변경
   - 기존 회원·상품·주문 데이터는 삭제하지 않음
9. 마이페이지 결제 상태
   - 가상계좌: 입금 대기 / 입금 확인 / 입금 완료
   - 미입금 가상계좌: 입금 전 주문취소
   - 휴대폰 결제 완료 후 DB 저장에 실패한 주문: 결제상태 확인으로 복구
10. 운영 관리 기능
   - 관리자 주문 상태 변경과 배송사·송장번호 관리
   - 회원 주문 상세 페이지와 배송 타임라인
   - 주문 상품별 배정 LOT·유통기한 추적
   - LOT 재고 10포 이하·유통기한 30일 이내 자동 경고
11. SALE ZONE 자동 할인
   - 남은 기간과 과잉 재고를 기준으로 10%·20%·30%·40% 자동 할인
   - 3일 이하 LOT 판매 중지
   - 메인 상단 SALE ZONE 메뉴 또는 /sale-zone에서 확인
   - 상세 정책은 SALE-ZONE-GUIDE-KO.txt 참고
12. 전문가 상담 UI 제거
   - 메인 버튼, 상단 메뉴, 상담 입력 영역 제거

[STS Import]
1. ZIP 파일을 원하는 새 폴더에 압축 해제합니다.
2. STS에서 File > Import를 선택합니다.
3. Gradle > Existing Gradle Project를 선택합니다.
4. Project root directory에서 압축을 푼 finalProject 폴더를 선택합니다.
   build.gradle 파일이 바로 보이는 finalProject 폴더여야 합니다.
5. Finish를 누르고 Gradle 동기화가 끝날 때까지 기다립니다.
6. Test3Application.java > Run As > Spring Boot App으로 실행합니다.
7. 브라우저에서 http://localhost:8080/ 으로 접속합니다.

[기존 H2 회원 데이터 유지]
기존 프로젝트의 data 폴더는 이 ZIP에 포함하지 않았습니다.
기존 회원·상품·주문·결제 데이터를 유지하려면 서버를 완전히 종료한 뒤 기존 data 폴더를
새 finalProject 폴더 바로 아래로 복사하세요.

현재 휴대폰에서 완료된 결제를 복구하려면 기존 data 폴더가 반드시 필요합니다.
새 프로젝트 실행 후 로그인 > 마이페이지 > 해당 주문의 '결제상태 확인'을 누르세요.
같은 주문을 다시 결제하지 마세요.

[관리자 환경변수]
관리자 로그인이 필요한 경우 STS Run Configurations > Environment에 다음 값을 등록합니다.
FEEDFLOW_ADMIN_USERNAME=admin
FEEDFLOW_ADMIN_PASSWORD=Admin!1234

[관리자 주문·LOT 화면 사용]
1. 관리자 계정으로 로그인하여 판매자센터로 이동합니다.
2. 판매자센터의 관리자 아이디·비밀번호에 같은 계정을 입력합니다.
3. '관리 데이터 불러오기'를 누릅니다.
4. 주문 관리에서 상품 준비 시작 → 배송사·송장번호 입력 → 배송 시작 → 배송 완료 처리 순서로 변경합니다.
5. LOT 재고·유통기한 경고에서 만료·임박·재고 부족 LOT을 확인합니다.

[회원 주문 상세]
마이페이지 > 주문·배송 내역 > 상세보기를 누르면 배송 타임라인,
배송사·송장번호, 결제정보와 주문에 배정된 LOT 번호를 확인할 수 있습니다.

[카카오페이 테스트 결제 확인서]
카카오페이 테스트 결제는 PG사가 실제 영수증 페이지를 제공하지 않을 수 있습니다.
주문 상세에서 '테스트 결제 확인서 보기'를 누르면 FEED FLOW 내부 확인서가 열립니다.
내부 확인서는 주문·상품·금액 확인용이며 법적·세무 증빙으로 사용할 수 없습니다.

[결제 키를 Import할 때마다 다시 입력하지 않는 방법]
1. Windows 사용자 폴더에 feedflow-config 폴더를 한 번만 만듭니다.
   예: C:/Users/본인윈도우계정/feedflow-config
2. 프로젝트 루트의 PAYMENT-CONFIG-TEMPLATE.properties를 위 폴더에 복사합니다.
3. 복사한 파일 이름을 payment.properties로 변경합니다.
4. payment.properties에 본인의 PortOne 값을 입력하고 저장합니다.
5. 이후 finalProject를 새로 Import해도 이 외부 파일을 자동으로 읽습니다.

외부 설정 파일이 없어도 애플리케이션은 정상 실행됩니다.
기존 STS Environment 값이 있으면 STS 환경변수가 외부 파일보다 우선하므로 충돌하지 않습니다.
payment.properties는 프로젝트 ZIP, Git, 메신저, 화면 캡처에 포함하지 마세요.

[비밀번호 재설정 사용]
1. 로그인 화면에서 비밀번호 찾기를 선택합니다.
2. 아이디, 이메일, 휴대전화를 입력하고 '인증번호 받기'를 누릅니다.
3. 기본 시연에서는 STS Console의 '[FEED FLOW 개발용 비밀번호 인증번호]'에서 번호를 확인합니다.
4. SENS 설정을 완료했다면 회원의 등록 휴대전화에도 같은 번호가 문자로 도착합니다.
5. 숫자 6자리를 화면에 입력하고 새 비밀번호를 설정합니다.
6. 인증번호는 5분간 유효하며 5회 틀리면 다시 발급해야 합니다.

문자 설정 방법은 SMS-AUTH-GUIDE-KO.txt를 확인하세요.
운영 서버에서는 FEEDFLOW_RECOVERY_CONSOLE_ENABLED=false로 설정해
인증번호가 서버 로그에 남지 않도록 해야 합니다.

[동시 주문·결제 보호]
- 같은 LOT을 여러 회원이 동시에 주문해도 행 잠금으로 순서대로 재고를 차감합니다.
- 같은 주문의 취소·결제 콜백이 동시에 들어와도 한 요청씩 처리합니다.
- 같은 PortOne 결제번호를 다른 주문에 다시 사용할 수 없습니다.

[공통 오류 화면]
- 존재하지 않는 주소: Feed Flow 404 화면
- 서버 처리 오류: Feed Flow 500 화면
- 내부 예외와 보안 정보는 브라우저 오류 화면에 표시하지 않습니다.
