FEED FLOW - STS 전체 프로젝트 Import 및 실행 안내

[중요: src만 복사하지 마세요]
이 압축 파일에는 src, build.gradle, Gradle Wrapper, Eclipse/STS 설정이 모두 들어 있습니다.
압축을 푼 finalProject 폴더 전체를 Import해야 합니다.

1. ZIP 압축 풀기
   권장 위치 예시:
   D:\dev\springboot\bootpl\finalProject

2. STS에 같은 이름의 finalProject가 이미 보이는 경우
   Package Explorer의 기존 finalProject 우클릭 → Delete
   기존 폴더를 보관하려면 "Delete project contents on disk" 체크를 해제하고 삭제합니다.
   같은 이름의 프로젝트가 Workspace에 남아 있으면 Import 화면에서 체크/Finish가 비활성화됩니다.

3. 새 완성본 Import
   File → Import → Gradle → Existing Gradle Project → Next
   Project root directory에 압축을 푼 finalProject 폴더 선택
   Finish
   Gradle 동기화가 끝날 때까지 기다립니다.

4. 관리자 기능을 사용할 때
   Run → Run Configurations → Spring Boot App → finalProject → Environment에서
   아래 환경변수를 원하는 값으로 등록합니다.
   FEEDFLOW_ADMIN_USERNAME=원하는관리자아이디
   FEEDFLOW_ADMIN_PASSWORD=원하는관리자비밀번호
   관리자 비밀번호는 소스코드나 application.properties에 직접 적지 않습니다.

5. 실행
   finalProject 우클릭 → Run As → Spring Boot App

6. 브라우저 확인 주소
   구매 홈(Thymeleaf HTML): http://localhost:8080/
   회원 마이페이지 HTML:   http://localhost:8080/mypage
   관리자 HTML:            http://localhost:8080/admin
   H2 Console:             http://localhost:8080/h2-console

7. H2 Console 로그인 값
   Driver Class: org.h2.Driver
   JDBC URL: jdbc:h2:file:./data/feedflow
   User Name: sa
   Password: 비워 둠

[화면 파일 위치]
src/main/resources/templates/index.html    고객 구매 홈
src/main/resources/templates/mypage.html  로그인 회원 전용 전체 마이페이지
src/main/resources/templates/admin.html   관리자 대시보드와 상품·LOT 관리

[반영된 이미지]
src/main/resources/static/images/feedflow-logo.png
src/main/resources/static/images/feed-bag-warehouse.png
src/main/resources/static/images/feedflow-farm-hero.png
로고는 헤더·푸터·로그인·관리자·favicon에, 사료 사진은 상품 화면과 관리자
미리보기에, 농장 사진은 구매 홈 메인 배너에 적용되어 있습니다.

[구현 확인 순서]
1) 홈 상품 검색과 전체/이벤트/소/돼지/닭·오리/영양제 필터
2) 상품 상세의 판매 가능 LOT, 유통기한 D-day, FEFO 안내
3) 장바구니 수량/총 중량/배송비
4) 회원가입 아이디 중복확인과 비밀번호·이메일 유효성 검사
5) 아이디 로그인 후 회원 전용 구매와 주문 완료
6) 마이페이지 최근 6개월 주문·관심상품·회원정보 수정
7) 관리자 상품 등록/수정/판매 중지와 재고/유통기한 상태
8) H2 Console에서 MEMBER, PRODUCT, PRODUCT_LOT, PURCHASE_ORDER 테이블 확인

[참고]
- React/Vite, npm, VS Code는 사용하지 않습니다.
- templates의 HTML과 static의 CSS/JavaScript를 Spring Boot가 직접 제공합니다.
- 비회원 구매와 정기배송 기능은 사용하지 않으며 로그인한 회원만 주문할 수 있습니다.
- 8080 포트가 사용 중이면 기존 Spring Boot 서버를 종료합니다.
- 서버가 재실행되면 로그인 세션은 종료되지만 상품과 주문은 H2 파일 DB에 유지됩니다.
