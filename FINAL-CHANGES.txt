FEED FLOW 최종 반영 내용

1. 회원가입 항목
   - 아이디(중복확인)
   - 비밀번호(영문, 숫자, 특수문자 포함 8자 이상)
   - 이메일(이메일 형식 검사)
   - 성명
   - 농장명
   - 휴대전화
   - 사업자번호
   - 자택주소
   - 상세주소
   - 농장주소
   - 하차위치

2. 로그인
   - 이메일 로그인을 아이디 로그인으로 변경
   - 로그인 전 상단 메뉴는 '로그인'
   - 로그인 후 상단 메뉴는 '마이페이지'
   - 일반 회원 로그인 성공 후 메인페이지로 이동
   - 관리자 로그인은 기존처럼 판매자센터로 이동

3. 주문
   - 로그인한 회원만 주문 가능
   - 비회원 구매와 비회원 주문조회 제거
   - 회원은 마이페이지에서 본인 주문만 조회하고 취소 가능

4. 제거 기능
   - 정기배송일
   - 정기배송 할인
   - 비회원 구매
   - 비회원 주문조회

5. 관심상품
   - 비회원은 관심상품을 등록할 수 없으며 로그인 화면으로 안내
   - 로그인 회원의 관심상품만 H2 DB에 회원별로 저장
   - 마이페이지에서 관심상품 조회 및 삭제 가능

6. 포트원 결제 검증
   - imp_uid 단건조회가 404인 경우 merchant_uid 주문번호 조회로 자동 복구
   - 복구된 결제의 imp_uid, 주문번호, 결제금액, 결제상태를 모두 교차 검증
   - 서버 검증을 통과한 결제만 결제완료로 처리

7. 기존 H2 결제 컬럼 자동 보정
   - 기존 DB의 payment_provider가 KAKAO/TOSS만 허용하는 문제 자동 수정
   - 기존 회원·상품·주문 데이터는 삭제하지 않고 PORTONE 저장만 허용

8. 무통장입금 주문 상태 및 취소
   - 가상계좌 발급 주문은 '입금 대기'로 표시
   - 입금 후 PortOne 검증을 통과하면 '입금 완료'로 표시
   - 입금 대기 주문에 '입금 확인'과 '입금 전 주문취소' 제공
   - 입금 전 취소 시 PortOne 가상계좌 발급취소 후 주문과 LOT 재고 복원

9. 결제 복구
   - 휴대폰 결제는 성공했지만 기존 H2 제약조건 때문에 저장에 실패한 주문 지원
   - 마이페이지의 '결제상태 확인' 버튼으로 PortOne 서버 상태를 다시 검증하여 복구

10. 검증
   - JavaScript 문법 검사 완료
   - H2 마이그레이션·PortOne 조회·가상계좌 취소 테스트 포함
   - 자동화 테스트 소스 16개 구성

11. 관리자 주문·배송 관리
   - 전체 주문을 최신순으로 조회하고 주문번호·회원·농장명으로 검색
   - 주문 상태별 필터 제공
   - 결제완료 → 상품준비중 → 배송중 → 배송완료 순서로만 변경
   - 배송 시작 시 배송사와 송장번호 필수 저장
   - 각 단계의 처리 시각을 H2 DB에 저장

12. 회원 주문 상세·배송 타임라인
   - 마이페이지 주문마다 상세보기 제공
   - 주문 상품, 금액, 배송지, 결제 정보 확인
   - 주문접수·결제완료·상품준비·배송중·배송완료 타임라인 제공
   - 주문 상품에 실제 배정된 LOT 번호와 유통기한 표시
   - 배송사·송장번호와 결제 영수증 확인

13. LOT 재고·유통기한 경고
   - 재고 10포 이하 LOT 자동 경고
   - 유통기한 30일 이내 및 만료 LOT 자동 경고
   - 위험도, 잔여일, 잔여수량과 권장 조치 표시
   - 관리자 대시보드 경고 건수 실시간 반영

14. 추가 검증
   - 관리자 주문 상태 전환·송장번호 검증 테스트 추가
   - 회원 주문 상세의 LOT 배정 검증 테스트 추가
   - LOT 재고 부족·유통기한 임박 경고 테스트 추가
   - 전체 자동화 테스트 메서드 18개 구성

15. 결제상태 확인 오류 수정
   - PaymentController의 주문번호 경로 이름을 명시하여 -parameters 옵션이 없어도 정상 동작
   - 결제 콜백과 관심상품 API의 경로·요청 변수 이름도 모두 명시

16. 카카오페이 테스트 결제 확인서
   - 연결되지 않는 mockup-pg-web.kakao.com 테스트 영수증 주소를 직접 열지 않음
   - 주문번호, 주문자, 결제수단, 결제상태, 상품명, 수량, 단가, 상품금액, 배송비, 할인, 총 결제금액을 내부 화면에 표시
   - 인쇄 기능 제공
   - 실제 카드전표·현금영수증·세금계산서가 아닌 테스트 문서임을 명확히 표시

17. 결제 키 외부 설정 유지
   - 사용자 폴더의 feedflow-config/payment.properties를 선택적으로 자동 로드
   - 프로젝트를 새로 Import해도 한 번 등록한 결제 설정 유지
   - 기존 STS 환경변수가 더 높은 우선순위로 적용되어 기존 실행 설정과 충돌하지 않음
   - ZIP에는 실제 키 없이 PAYMENT-CONFIG-TEMPLATE.properties 양식만 포함

18. 비밀번호 찾기 보안 강화
   - 아이디·이메일·휴대전화 확인 후 6자리 일회용 인증번호 발급
   - 인증번호는 무작위 salt가 포함된 SHA-256 해시만 메모리에 보관하고 API 응답에는 번호를 노출하지 않음
   - 인증번호 5분 만료, 30초 재발급 제한, 5회 실패 시 즉시 폐기
   - 인증 완료 전에는 새 비밀번호 변경 불가
   - 로컬 시연용 인증번호는 STS Console에만 출력

19. 재고·주문 동시성 방지
   - FEFO LOT 재고 차감 쿼리에 PESSIMISTIC_WRITE 행 잠금 적용
   - 주문 취소 재고 복원 전 주문과 관련 LOT을 함께 잠금
   - 관리자 주문 상태 변경에도 주문 쓰기 잠금 적용
   - 잠금 충돌 시 409 응답과 재시도 안내 제공

20. 결제 중복 처리 방지
   - 결제 콜백·웹훅·결제상태 복구 시 주문 쓰기 잠금 적용
   - 같은 PortOne imp_uid 재호출은 기존 결제 완료 결과 반환
   - 다른 주문에서 사용한 imp_uid는 거부
   - H2 provider_transaction_id 고유 인덱스를 자동 생성

21. 공통 오류 페이지
   - Feed Flow 디자인의 404, 500, 기타 오류 화면 제공
   - 내부 예외 메시지, 스택트레이스, 바인딩 오류를 기본 오류 화면에서 숨김

22. 검증
   - Java 전체 소스와 테스트 소스 컴파일 확인
   - Spring/JUnit 전체 테스트 20개 통과
   - JavaScript 5개 파일 문법 검사 통과
