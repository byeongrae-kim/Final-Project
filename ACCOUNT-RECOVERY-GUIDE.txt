FEED FLOW 아이디 찾기 / 비밀번호 재설정 안내

1. STS Import
   File > Import > Gradle > Existing Gradle Project
   ZIP을 푼 뒤 finalProject 폴더를 Project root directory로 선택합니다.

2. 실행
   finalProject 우클릭 > Run As > Spring Boot App
   브라우저에서 http://localhost:8080/ 으로 접속합니다.

3. 아이디 찾기
   로그인 창 > 아이디 찾기
   회원가입 때 입력한 성명과 이메일을 입력합니다.

4. 비밀번호 찾기
   로그인 창 > 비밀번호 찾기
   아이디, 이메일, 휴대전화가 기존 회원정보와 일치하면
   영문·숫자·특수문자를 포함한 8자 이상의 새 비밀번호로 변경됩니다.

5. 관리자 계정
   환경변수로 설정한 관리자 계정은 일반 회원의 아이디 찾기와
   비밀번호 재설정 대상이 아닙니다.

주의
   현재 기능은 H2 기반 학습·시연용 본인확인 방식입니다.
   실제 서비스에서는 이메일 인증번호 또는 일회용 재설정 링크를 추가해야 합니다.
