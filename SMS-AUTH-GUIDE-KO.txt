FEED FLOW 휴대전화 인증번호 안내

기본 발표 구성 (가입·비용 없음)
1. 회원이 아이디, 이메일, 등록 휴대전화를 입력합니다.
2. 세 정보가 H2 회원정보와 일치하면 6자리 인증번호가 생성됩니다.
3. STS Console에서 다음 문구를 찾습니다.
   [FEED FLOW 개발용 비밀번호 인증번호]
4. Console에 표시된 6자리 번호를 브라우저에 입력합니다.
5. 인증번호는 5분간 유효하고 5회 틀리면 폐기됩니다.

실제 휴대전화 SMS 발송 (선택 기능)
1. Naver Cloud Platform에서 SENS SMS 서비스를 신청합니다.
2. SMS 프로젝트와 발신번호를 등록합니다.
3. 프로젝트 루트의 SMS-CONFIG-TEMPLATE.properties를 복사합니다.
4. 다음 위치에 sms.properties라는 이름으로 저장합니다.
   C:/Users/본인윈도우계정/feedflow-config/sms.properties
5. sms.properties에 SENS 서비스 ID, Access Key, Secret Key,
   등록 발신번호를 입력하고 sms-enabled=true로 변경합니다.
6. Spring Boot를 완전히 종료하고 다시 실행합니다.

정상 작동하면 동일한 인증번호가 등록 휴대전화와 STS Console에 표시됩니다.
프로젝트를 다시 Import해도 사용자 폴더의 sms.properties 설정은 유지됩니다.

보안 주의사항
- Access Key와 Secret Key는 프로젝트 ZIP이나 Git에 넣지 마세요.
- 실제 운영에서는 Console 출력을 false로 변경하세요.
  feedflow.security.password-recovery.console-enabled=false
- 발송 실패·과도한 재발급을 확인하고 SENS 사용량과 과금을 점검하세요.
